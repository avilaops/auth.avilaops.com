# Narrativa — auth.avilaops.com

## Classificação

Capacidade interna crítica do ecossistema Ávila Ops.

## Domínio

`auth.avilaops.com`

## Idioma

Português.

## O que é

Login único, permissões, painel de contas e conectores de autenticação dos
produtos da Ávila Ops.

## Público

Equipe Ávila Ops e sistemas consumidores. Cliente final só deve enxergar este
serviço como "entrar com segurança", não como produto separado.

## Posicionamento interno

É infraestrutura de confiança. Não entra no catálogo comercial e não recebe
prospecção própria. Os produtos comerciais usam o `auth` como base para reduzir
atrito de acesso e manter controle de permissões.
